# 掌心刷题联动范围与后续协议

## 本轮已经实现

- 考试档案和个人页有掌心刷题入口。
- 考试档案中的动作会先复制考试名称，再打开真实网页版 https://wiseliang.cloud/palm-quiz/ 。
- 可从发布页 https://wiseliang.cloud/palm-quiz/release/ 下载掌心刷题。
- 使用掌心刷题自己的登录和题库，用户自行选择匹配题库或导入资料。
- 未收录考试可以在考试通个人添加，同样使用上述入口。

本轮没有修改掌心刷题仓库、生产服务或用户题库。既有考试通 ID 和个人题库 ID 不相同，不能直接互用。

## 已核实的接收端情况

阅读用户授权的私有仓库 `wiseliang/palm-quiz` 的说明、Android Manifest、Activity 与网页入口代码后，确认已有题库、导入、练习和考试功能，但没有用于接收考试通考种标识的公开 deep link 协议。仓库内容保持私有，本项目不包含题目、账户或其服务端实现。

## 拟议的第二阶段：带上下文进入题库

以下均为待开发的协议，不是现有可调用接口：

1. 公共考试以带来源的稳定标识映射；个人考试使用不含账户信息的独立标识和名称提示，不能用本机负数 ID 假装跨设备唯一。
2. 接收考试名称、公开标识、可选科目及来源；不放密码、Cookie、登录 token 或私人题目。
3. 掌心刷题在登录后展示候选题库，由用户确认。没有匹配时展示导入入口，不自动创建、覆盖或选中同名题库。
4. 未安装 App 时打开网页登录流程；未登录时保留待处理跳转，登录完成后再继续。
5. 来自外部的字段做长度、来源、协议版本与 URL 白名单校验，禁止把返回地址当作任意脚本或内部请求。
6. 用独立演示账户验证未登录、无题库、多候选、无网络和拒绝授权等路径。

## 拟议的第三阶段：备考汇总

在有明确授权和考试—题库映射后，可展示已练题量、最近学习日期、待复习数量。仅交换实现用户功能所需的汇总，不搬运私人题库全文；权限撤销后停止读取。真实双向联动需同时修改并验证接收端。

## 当前验收边界

考试通端的按钮、复制和外部网页打开可以独立验证。Android 的真实浏览器跳转、掌心刷题登录及题库选择仍需真实设备试用，不能把“入口已接上”描述成“进度已经同步”。
