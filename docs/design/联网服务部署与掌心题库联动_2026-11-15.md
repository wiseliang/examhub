# 考试通1.4：联网服务与掌心题库联动

## 已部署的备考服务

正式地址：https://wiseliang.cloud/examhub-assistant 。HTTP接口协议仍为v1，沿用1.3的研究、轮询和取消接口。1.4客户端预填地址，使用单独的个人访问码连接；访问码通过私有交付文件提供，不在GitHub、APK、截图或日志中。

服务以独立的系统服务`examhub-assistant.service`运行，监听127.0.0.1:8788；HTTPS站点新增专属前缀，关闭该入口的访问日志和响应落盘缓存。部署前保存原配置，通过nginx配置检查后平滑重载。掌心刷题未重启，原题库和账号数据库未改动。

使用当前服务身份已授权的Codex登录，单并发、每次最多240秒研究并回收进程，没有安装本地Flutter/Android/Gradle工具链。部署后记录的空闲服务内存约30MiB，是一次实测值，不代表运行AI任务时的峰值。

2026-11-15经公开HTTPS入口实测：有访问码健康检查200，无访问码401；使用明确App标识及Accept: application/json请求头。研究目标为上海NCRE二级Python，2027-03-01个人截止日，每个学习日45分钟、只周末学习，实际5次搜索工具完成事件，返回7个来源、3个候选，生成31个学习日、62项任务。逐项检查所有任务均在周末且每日不超过45分钟。此结果是AI检索整理，未人工逐条核验网页、费用及授权。

掌心刷题公开健康接口仍返回200和既有版本0.20.12；未认证题库接口返回401。未使用真实用户账号或真实题库做自动化登录测试。

## App连接方法

首页“让助手帮我备考” → 右上角设置 → 检查预填地址 → 粘贴个人访问码 → 连接。地址可保存，访问码当前只留在App进程内，重启后重新填写。旧版1.3也可手动填写同一地址连接。

个人访问码仅用于备考服务；掌心刷题账号和密码则在“我的掌心题库”界面输入，二者不同。

## 从掌心刷题选择已有题库

助手右上角书本图标，或结果中的“查找我的掌心题库”，进入授权登录界面。输入自己的掌心刷题账号和密码，客户端直接调用其现有HTTPS登录接口；会话仅在App进程内保存，登录密码不存入数据库。

登录后仅请求当前账号有权访问的题库元数据列表，显示名称、实际题数及个人/共享属性。可按考试名称或关键词查找，选中后保存为当前备考入口的参考题库，并提供“复制题库名并打开掌心刷题”。打开目标App后仍需核对其当前账号并选择对应题库。尚未共享两个App的登录会话或直接跳入具体题库。

名称查找是可解释的文本匹配，不能证明年份、大纲、答案质量或合法导入范围完全匹配。未匹配时可以缩短关键词或查看全部有权访问的题库。选择记录只含题库id、标题、题数、共享属性和对应用户id，不含密码或登录会话。

登录信息和题库列表不发送给备考模型。发起研究仍只包含用户填写的考试目标、地区、基础、偏好、截止日与时间安排；题目正文不会因选择题库而被下载或送去分析。

## API契约及边界

客户端直接使用掌心刷题现有接口：

- POST /palm-quiz/api/login：用户名与密码，返回当前账号会话。
- GET /palm-quiz/api/banks：Bearer会话，返回有权访问的题库元数据。
- POST /palm-quiz/api/logout：退出该次登录会话；即使网络失败，也清除本地会话。

凭据请求固定到掌心刷题HTTPS域名，禁止自动跟随重定向。备考服务请求也禁用自动重定向。需要新账号时转到掌心刷题自身页面注册，考试通不代建用户。

本阶段没有自动导入网页题库、自动购买、跨App登录同步、按题目内容验证大纲覆盖率或回传正确率/错题/耗时。后续接入进度和错题需要明确定义授权数据范围与接口，不能用题库名称或题数伪造掌握程度。

## 验证与维护

新增独立演示数据测试覆盖登录前禁止读取题库、按名称匹配、会话随请求使用、退出失败清除本地会话、窄屏登录/选择闭环，以及题库选择不被加入模型研究目标。截图中的账号和题库全部为演示数据；真实联网搜索和演示题库列表是不同验证。

构建仍全部通过GitHub托管runner生成ARM64优化APK。测试包暂用调试签名，遇到签名不一致不要直接卸载，以免丢失本地计划；正式分发需固定签名。

服务升级将server目录部署到仓库外独立版本目录，运行Node检查后切换系统服务的绝对入口；保留上个版本和nginx配置快照。不要通过符号链接脚本路径直接启动1.3入口：该版入口判断比较import路径与argv，部署单元需使用实际版本目录的绝对脚本路径。

轮换个人访问码时修改仓库外受限环境文件并重启仅备考服务；服务内存中的未完成任务会失效，App已保存的计划不受影响。回滚也仅操作备考服务和新增nginx片段，先校验配置再重载。
