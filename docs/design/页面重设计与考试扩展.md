# 页面重设计与考试扩展

## 设计方向

考试信息工具的首要动作是找考试、确认安排、开始准备。页面采用“备考工作台”，不以预设评分或虚构热度组织内容。

- 深墨 #17213A：标题与主要文字。
- 备考蓝 #254FD5：主要动作与“我的备考”焦点区域。
- 雾蓝 #F3F6FC：页面底色。
- 纸白 #FFFFFF：阅读区域。
- 核验绿 #117C6F：已核验状态。
- 正文灰 #52617E：说明文字，避免过浅小字。
- 中文使用系统无衬线字体，主标题 30 / 栏目 21 / 正文 15 / 辅助 13，左对齐。
- 焦点仅保留在“我的备考”区域；目录使用清楚的行与分隔，不把每个内容都做成有阴影的卡片。
- 去掉装饰性 emoji、满屏星级、渐变背景和无依据的排行榜。

## 页面结构

```text
备考                        添加考试
你的下一场考试
[搜索考试名称、行业]
[我的备考：关注与个人目标日期]
考试目录                    查看全部
考试名称           行业 / 资料状态
考试名称           行业 / 资料状态
[没找到？添加自己的考试]
---------------------------------
备考              考试库       我的
```

考试库：搜索、行业选择、筛选、结果列表；无结果时直接预填名称添加。
详情：考试档案与来源状态、报名条件、科目、年份/地区/批次安排、明确的关注与刷题入口。
我的：已关注、自行添加、收藏、浏览历史，均可进入详情。

## 未收录考试

在首页、考试库无结果页与个人页均可添加。名称必填，可补充行业、官网与个人目标日期。保存到本机并自动关注，标记“个人添加”，不假装已被官方核验或已提交公共收录。重复名称打开现有考试，个人 ID 使用负数，避免后续公共目录更新覆盖。

## 掌心刷题接入范围

已阅读用户授权的私有掌心刷题仓库。现有网页入口为 https://wiseliang.cloud/palm-quiz/ ，发布页为 https://wiseliang.cloud/palm-quiz/release/ 。当前没有接收外部考试标识的标准 deep link，个人题库 ID 也不等于考试通 ID。

本轮提供真实网页入口与考试名称复制，用户在掌心刷题选择或导入题库。不读取、不复制私人题库，不跨应用共享登录凭据，不声称题库自动匹配或学习进度已互通。

后续深度联动应约定带版本的考试标识映射、登录后的待处理跳转、无匹配时的导入入口，以及经用户授权的学习汇总。接收端与发送端都需要测试，不能只拼接目前不会处理的 URL 参数。

## 设计复核

初稿若继续使用相同圆角卡片、预设星级和彩虹标签，会延续原页面的问题。因此目录改为有明确对齐和分隔的档案列表，删除评分排序，仅保留必要状态；大面积蓝色只出现于备考焦点区。录入、空状态与外部跳转均使用真实可执行动作。
